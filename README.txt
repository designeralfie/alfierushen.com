Alfie Rushen portfolio — self-hosted

Upload the whole folder (index.html + images/) to any static host:
Netlify Drop, GitHub Pages, Cloudflare Pages, or your own server.

To edit:
- Project text, roles and image lists live in the PROJECTS block near the bottom of index.html.
- Add images to images/projects/ and replace a null in that project's "images" list with the path,
  e.g. "images/projects/mapp-02.jpg". "cover" is the homepage thumbnail.
- Brand logos: images/logos/ and the BRANDS list. Swap in official SVGs when you have them.
- Your CV is cv.pdf in this folder; replace it with a newer PDF of the same name to update it.
- Each project opens at yoursite.com/#mapp, #amnesty, etc., so you can link to a project directly.
